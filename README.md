# Tiny Empire

Build a tiny business empire, one tap at a time.

About

Tiny Empire is a lightweight browser idle/clicker game. The live build is hosted on GitHub Pages (link above). This repository is the source for the game and the live deployment.

Quick notes

- Latest tested mobile viewports: 320×780, 375×812, 390×844.
- The UI has been adjusted to avoid the bottom navigation overlapping the daily missions card. If you still see clipping on some devices, try a hard refresh (clear cache) or report the viewport and a screenshot.
- Balance: the game has been tuned toward a slower, more grindy idle experience. Prestige target and scaling changes were made in recent commits — see src/data.js for exact values.

Developer / QA checklist

- Run the live build and verify the three mobile viewports above.
- Test a fresh save to make sure progression pacing feels right.
- Export/Import save to confirm save compatibility.
